### A4 · Language switcher

**A switcher exists on every page.** It is rendered by `shell.js` into the header.

**It is not an `<a href>`.** It is two `<button type="button">` elements inside
`<div class="lang-switch" role="group">`, carrying `data-lang="en"` and `data-lang="ja"`.

`aria-pressed="true"`.

from a `data-en-url` / `data-ja-url` attribute on `<body>` and assigns it to
`window.location.href`. If the current URL carries a fragment that names an element
present on the page, and that fragment is not `#main`, it is appended so the reader
lands on the same section. A page that declares no counterpart does nothing on click.
