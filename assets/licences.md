# Asset licences

The provenance record for every image, map, logo and font shipped in this
repository. One row per file. Nothing should reach production without a
verified entry here.

**Status key**

| Status | Meaning |
| --- | --- |
| `VERIFIED` | Source and licence confirmed from the file itself or from a first-party record. |
| `ASSERTED` | Believed correct and recorded by the site owner, not independently verifiable from the file. |
| `OUTSTANDING` | **No source or licence on record. Must be resolved before the asset can be relied on.** |

## 4. Focus maps — `assets/maps/`

Derived vector maps, generated by `build_prod.py` from open data. Each file
carries its full source note in an SVG comment in its own head; the summary
below is the licence position. Focus areas are indicative and do not represent
administrative boundaries.

| File | Used on | Status |
| --- | --- | --- |
| `amsterdam-wide.svg`, `amsterdam-tall.svg` | `about.html` | `VERIFIED` |
| `london-wide.svg`, `london-tall.svg` | `about.html` | `VERIFIED` |

**Amsterdam — boundaries**
Gemeente Amsterdam *gebiedsindeling*, *buurtcombinaties*. Licence: CC0 1.0
(public domain dedication). Mirror: `blackmad/neighborhoods`. Projection
EPSG:28992.

**London — boundaries**
ONS Wards (December 2013) Boundaries and Local Authority Districts, Open
Geography Portal. Contains public sector information licensed under the
**Open Government Licence v3.0**. Mirror: `martinjc/UK-GeoJSON`. Projection
EPSG:27700.

**Both cities — transport, land use and water**
Overture Maps Foundation, release 2026-08-19.0 (`transportation/segment`,
`base/land_use`, `base/water`). Licence: **ODbL 1.0**,
© OpenStreetMap contributors.

> **Attribution obligation.** ODbL 1.0 and OGL v3.0 both require visible
> attribution wherever the derived maps are published. The maps currently
> carry their attribution only in an SVG source comment, which is not visible
> to a reader. A visible credit — a caption near the maps on `about.html`, or
> a line in the footer — should be added to satisfy both licences.
