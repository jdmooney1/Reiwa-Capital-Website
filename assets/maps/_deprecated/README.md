# Deprecated map prototypes — not used by the site

These four SVGs were generated experiments and are **superseded**. They are
kept only as a record of the prototype and must not be referenced from any
page.

    london-wide.svg      london-tall.svg
    amsterdam-wide.svg   amsterdam-tall.svg

They were built from statistical boundaries (ONS LSOA/MSOA for London,
buurten for Amsterdam) plus hand-authored Amsterdam canal geometry. That
approach was rejected: it reads as a GIS export rather than institutional
real-estate research.

The build scripts that produced them were session scratch files and were
never committed. They are not being maintained.

The final maps will be professionally rendered static image assets placed
at `assets/maps/` — see the Focus Markets section of `about.html` for the
expected filenames and the container specification.
